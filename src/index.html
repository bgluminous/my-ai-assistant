功能概览

账户管理

保存 Cursor / ChatGPT 账户，查看套餐、额度与存活状态，支持定时刷新与一键切换。

用量统计

按账户与模型汇总 Token，折算等价官方 API 费用，并绘制按日堆叠柱状图与模型图表。

审计日志

记录账户变更、刷新失败与续期结果，可筛选与清空。

系统托盘

关闭窗口后继续后台运行，托盘面板可查看额度并切换账户。

显示与代理

可切换 Token 单位、配置客户端路径与网络代理。

使用说明

  • 本应用调用 Cursor / OpenAI 的非公开内部接口，随时可能变动或失效。
  • Token 只发往官方域名，不会发到第三方。
  • 仅供个人本地使用，请遵守相应服务条款并自担风险。
