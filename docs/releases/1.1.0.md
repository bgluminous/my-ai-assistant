### 新增

- 支持通过环境变量指定独立数据目录，可与默认实例并行运行，分别保存设置和账户数据。
- 账户页可退出本机 Cursor、ChatGPT 或 Claude Code 登录，操作前备份并记录审计日志。
  退出仅影响对应本机客户端，应用中托管的账户保持不变。
- 已删除的 Cursor 账户可手动指定套餐档位，统计表的套餐、月费和费用倍数随之更新。

### 修复

- Cursor 会话失效后保留上次套餐与计费周期信息，删除并保留统计时也会保存这些信息。
- 托盘总览纳入已删除账户保留的统计数据，与统计页采用相同口径。
- 本机 ChatGPT 已退出登录或仅使用 API Key 时，后台同步不再误报凭据文件解析失败。
