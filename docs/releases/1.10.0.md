## 新增

- 新增 OpenCode 账户管理，支持 Go / Go Plus / Go Teams 套餐、成员额度和工作区余额。
- 添加 OpenCode 时可选择本机导入或独立 OAuth 授权，并填写备注；支持 V2 客户端切换。
- 账户分组卡片支持拖拽排序，保存顺序并同步刷新顺序，备份恢复时一并还原。
- 各类账户支持独立同步间隔，默认跟随全局，可单独关闭，并随账户导出与备份保留。
- 用量统计新增账号与来源的 Token 构成图，四张环形图按两行两列排列。
- 支持工作区官方模型用量归档、时间范围统计和历史覆盖提示，按官方 API 价折算等价费用。
- 账户页、托盘、用量总览及备份恢复加入 OpenCode，并补充接入与使用说明。

## 优化

- 用量统计与快照移除实际支出、实扣及官方记录成本，保留等价费用、Token 与套餐倍数。
- 日及自定义时间范围同样显示套餐倍数，账单表统一展示月费，OpenCode 名称沿用账户备注。
- 扩宽默认窗口，完整展示用量摘要；凭据有效期移到状态第二行。
- 各类账户的读取异常改为感叹号悬停提示，保持账户行布局稳定。
- OpenCode 未填备注时默认使用邮箱，统一编辑框样式并隐藏空提示条。
- 编辑弹窗统一二次点击遮罩关闭，Esc 使用相同提示；美化公共提示，保存中防误关。

## 修复

- 修复设置写盘失败仍会删除 OpenCode 归档的问题，失败时保留原有内存状态和归档。
- 修复授权取消失败后无法再次取消的问题，避免遗留授权阻塞后续客户端切换。
- 全量备份恢复 OpenCode 客户端路径；归档整批恢复，失败时明确显示部分恢复结果。
- 备份导入与手动修改路径共用原生授权保护，避免授权中途切换客户端路径。
