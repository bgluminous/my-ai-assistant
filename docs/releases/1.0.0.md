### 新增

- 集中管理 Cursor、ChatGPT 与 Claude 账户，支持添加、导入导出、定时刷新和切换本机登录。
- 查看账户套餐、额度窗口和重置时间；主窗口与托盘共享刷新状态和账户显示顺序。
- 统计 Cursor 账单及本机 Codex、Claude Code 会话用量，按模型查看 Token、实扣与等价费用。
- 支持日、周、月、全部和自定义时间区间，可多选统计对象，并在托盘按天查看用量。
- Cursor 用量支持增量保存和本地查询；删除账户时可保留统计数据，重新添加后继续沿用。
- 支持生成全量用量快照、查看原始账单、导出 CSV 和清除单个账户的本地用量数据。
- 提供模型价格表编辑与在线更新，支持模型别名、Fast 档位及未定价提示。
- ChatGPT 凭据支持加密副本、自动续期和与本机客户端双向同步，切换时显示凭据处理状态。
- 支持全量数据备份与合并导入，可为备份设置密码；支持开机启动和仅驻留托盘的静默启动。
- 提供按级别与分类筛选的审计日志，以及显示出口 IP、地区和 ISP 的代理连接测试。

### 优化与修复

- 本机 Codex 用量按会话谱系去重，避免分叉会话和复制的父会话历史重复计入。
- 失效账户继续保留已缓存的用量和显示名称，已删除账户可编辑备注。
- 改善托盘窗口、长账户名称、图表提示和刷新交互，减少启动白闪与重复刷新。
- 用户数据迁移至统一目录，启动时自动搬迁旧目录中的数据。
