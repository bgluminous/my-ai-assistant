## 新增

- OpenCode、GPT / Codex 和 Claude 支持同时切换已安装的 CLI 与 Desktop，也支持单端使用。
  主窗口和托盘会分别显示各端结果，运行中的 CLI 会话会保留。
- Claude Desktop 可在账户编辑中绑定登录。完成或取消绑定后会恢复原登录，
  中断后可从编辑或切换窗口恢复。桌面登录快照仅保存在本机。
- GPT / Codex 支持按本机配置读取文件、系统钥匙串和加密凭据存储，
  用于账户导入、切换、退出和凭据同步。
- ChatGPT、Claude 和 OpenCode 可按账户关闭「自动续期 Token」。
  关闭后仍可用现有 Token 查询，主动切换、修改凭据和重新授权沿用原流程。
- 内置价格表新增 GPT-6.2 Astra / Sol 的标准与 Fast 档，共 4 项。
- `codex-auto-review` 和 `default` 仍统计 Token 用量，等价费用按零价计算。

## 优化

- Cursor、ChatGPT、Claude 和 OpenCode 刷新各自排队，同一供应商按顺序执行，
  不同供应商可并行，慢请求不会拖延其他供应商的下次刷新。
- OpenCode Desktop 可使用内置 CLI；两端共用数据库时只切换一次，
  独立数据库分别切换。切换或启动失败时尝试恢复对应登录。
- OpenCode 原生授权遇到临时查询错误后会继续等待，授权结束后会显示结果。
